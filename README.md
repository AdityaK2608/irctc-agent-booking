# IRCTC Agent Booking

A web application for managing an authorized railway-agent booking workflow.

## Scope
- Customer booking requests
- Passenger profiles
- Agent dashboard
- Booking and PNR records
- Receipts and reporting
- Future integration with an officially permitted IRCTC/authorized-agent API or workflow

## Compliance
This project is designed for authorized agent operations. It must not bypass CAPTCHA, OTP, payment controls, queues, rate limits, anti-bot systems, or other access controls.

## Planned structure
- `frontend/` — customer and agent web interfaces
- `backend/` — API and application services when needed
- `docs/` — integration and operational documentation
